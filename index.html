Free, open verification tools for Super Intelligence

Mission: build superintelligence.

Our position: self-improving AI is limited by verification. A system can only improve as fast as it can tell a real improvement from a fooled check, and today's checks are fooled more often than anyone measures.

What we ship: free, open tools that measure whether AI results are real, released on a fast cadence.

gameability v0.2

Runs on a laptop, no model or API key. Finds problems in a code benchmark that accept broken solutions. It breaks each problem's reference solution in one small place, confirms the result is really wrong, then checks whether the problem's own tests notice.

rsi-audit v0.1

Checks a self-improvement or agent-leaderboard claim from its public artefacts.

View the five checks & documentation →

$ pip install rsi-audit

Five checks

  • ranking: does the order survive resampling tasks
  • visibility: can the agent read the grader's tests or answers
  • selection: was the reported system picked on the graded tasks
  • luck: how many record claims could pass by chance
  • card: 12 requirements a self-improvement number needs

The 12 card requirements

REQUIRED matched control
REQUIRED matched compute
REQUIRED repeated training runs
REQUIRED intervals
REQUIRED held-out final evaluation
REQUIRED attempts reported
REQUIRED correctness gate covers what is scored
REQUIRED cheats scored as failures
REQUIRED hidden grader
REQUIRED resampled ranking
REQUIRED pre-committed task set
REQUIRED disclosed harness

Audits

We audit published self-improvement claims and leaderboards. Each audit goes privately to the authors first; the write-up appears here once they have had the chance to reply.
